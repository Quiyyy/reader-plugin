# 0.2.18：宿主缩放定位与笔记侧栏

修复在 Codex 等嵌入式宿主中拖拽面板宽度后，阅读器及笔记回到顶部的问题。独立浏览器视口测试没有覆盖 iframe 尺寸变化后的原生滚动重置：旧代码在 `ResizeObserver` 回调中恢复后，仍可能被后续布局覆盖。现在于后续布局帧恢复内容锚点，并在用户主动滚动或跳转时交还控制。

笔记宽屏的左右留白会随窗口变化，正文宽度可能保持不变，因此尺寸监听改用 `border-box`。排版笔记以文字或空段落定位；源码使用相同排版的测量元素记录字符位置，避免为了计算高度临时把 textarea 收缩为零。

主导航和目录与正文并排显示，宽窄屏沿用同一结构。打开侧栏自动隐藏输入区，关闭后恢复用户此前的显示选择。底部保存状态与输入框开关在同一行；手动隐藏不会清空草稿，选区提出修改要求会展开输入区。右上角 AI 入口移除，评论入口保留。

回归使用原创内容及真实 AppBridge 的隔离 iframe，覆盖连续缩放及回到原宽、源码与排版、侧栏正文可见性、目录跳转、输入区开关与草稿保留。该测试宿主不等于实际 Codex 页面验收。
