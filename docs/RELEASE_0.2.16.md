# 0.2.16 快速记录与独立配置

- Note Bot 任务默认直接写入当前笔记，聊天仅报告简短结果或提出必要问题。写入前读取笔记，任务内追踪版本；其他窗口或用户保存了新版本后，旧任务不能强行覆盖。
- 原建议会话可继续使用，明确发送新任务时切换为直接编写；聊天历史保留。最近一次工具修改可在展开对话后撤销。
- 保存状态和展开／收起对话在同一状态行。“+”菜单锚定输入框里的按钮，点击外部或按 Esc 自动隐藏。
- 两种编辑模式共享正文默认字号，初始为 14px；在“笔记操作 → 默认字号”中调整，设置保存在本地书库并用于后续笔记。
- “快速笔记”入口直接创建空白笔记、打开编辑器并聚焦正文；新笔记归入当前书库文件夹。创建期间的重复点击只产生一份笔记。
- 已有笔记通过书库或编辑器菜单中的“全部笔记”浏览，继续支持搜索与管理。
- Note Bots 使用独立配置页面，无遮罩弹窗。宽窄屏使用同一套单列表单，内容垂直滚动、保存操作固定在页底。
- 切换配置页面前保存笔记与对话草稿；返回后保留编辑页面及当前 Bot 配置草稿。切换 Bot 时保留未提交的表单输入。
- 文字笔记封面统一使用简洁图标与纸张线条，正文和 Markdown 符号不再出现在封面上；图片笔记使用原有缩略图，标题显示在封面下方。
- 同步原生平台安装验收的 Note Bots 工具清单，继续严格检查工具全集与 app-only 可见性。

相关交互在隔离书库检查，覆盖 320px、390px 与宽屏，以及返回、保存、重复点击和笔记原文保留。交付遵循 [本地更新方案](LOCAL_UPDATES.md)，不自动追加宿主页面复核。
