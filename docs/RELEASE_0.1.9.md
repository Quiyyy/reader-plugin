# Reader 0.1.9

本版基于正式 0.1.8，保留回收站、阅读状态、书源清单及快捷键设置的数据格式。版本、MCP 标识与 UI 资源 URI 同步更新，避免复用旧版界面缓存。

- 修复正常长目录被 5 页硬限制拒绝：目录与正文分批保存续点，支持继续、失败页重试和服务重启；完整后才替换目录或缓存。移除搜索前 5 页截断，调整长目录规则计数和 Worker 生命周期，同时保留累计资源、循环检测及安全边界。详见 [规则限制审计](RULE_LIMITS_AUDIT_0.1.9.md)。
- 设置优先展示外观，键盘与书籍操作入口对齐；快捷键按阅读和面板操作分组，录制、冲突提示、清除和恢复默认集中呈现。书源域名与状态同排，清单详情默认折叠，兼容性提示保持可见。
- EPUB 可接受名称、SYSTEM 或 PUBLIC 形式且不含内部子集的 DOCTYPE。解析前移除声明，不请求外部 DTD；内部子集、实体声明、重复或畸形声明仍拒绝。此修复覆盖真实书籍导入、阅读与重启恢复。
- 普通公开网页含已知 Cloudflare JavaScript Detections 脚本时，不再仅因该脚本路径误判为挑战页。响应含 `cf-mitigated: challenge` 仍立即拒绝，包括 HTTP 200；实际挑战标记、登录页及其他挑战路径仍受原有保护。不会执行检测脚本、获取挑战 cookie 或绕过访问控制。

依赖、QuickJS 隔离执行和 SafeHTTP 网络边界不变。本版不迁移书籍或书源存储；升级前仍需备份当前书库、设置和安装摘要。旧版 0.1.8 可用于回退，恢复数据时须保留升级后新增的阅读进度。

## 验证范围

功能候选已通过六平台原生包及 Windows、Mac、Linux 检查矩阵。UI 已在 320、390、1280 宽度和键盘场景中检查。真实 EPUB 原文件保持不变，隔离安装完成目录、正文、进度及服务重启检查。Kanripo 候选规则已在修复引擎完成实际网络检索、目录、正文和重启验证；正式包的最终验收与书源 ready 清单由独立书源项目确认。仅格式兼容不能证明网站可读，超时或未验收候选不会自动成为可用源。

发布须由 0.1.9 对应 CI 和 main 稳定分发门禁完成；测试宿主与 CI 通过不代表真实 ChatGPT 界面已验收。公开宿主关闭请求仍仅报告不支持、失败或已发送，不能保证面板已关闭。Reader 不隐藏 iframe、不使用私有 RPC、不捕获宿主全局快捷键；输入框、contenteditable 和 IME 的方向键行为保留。

本次授权升级 Windows 正式安装，保留全部用户数据。不会升级用户 Mac；原有 Mac 签名、公证和目录限制不变，也不修改已暂停的效率改造 workflow。
