# Reader 0.2.4 · 当前笔记目录

笔记编辑页默认不显示左栏。原来的列表折叠按钮替换为阅读页同款 `List` 目录按钮，展开后仅展示当前笔记内部的标题；笔记总览通过返回入口访问，不再占据编辑页左侧。

目录支持一至六级 Markdown 标题及下划线式标题，排除围栏和缩进代码中的标题。相同标题按正文位置区分；输入内容修改后目录随即更新。编辑模式按实际字体和换行测量目标位置，定位光标；预览模式定位对应标题。选中目录项后关闭面板，`Esc` 返回目录按钮，`T` 仅在非编辑控件中切换目录。

验证：3 项解析测试、16 项笔记与工作台浏览器检查通过。覆盖默认关闭、旧折叠偏好不影响新行为、重复标题、长行换行、预览定位、动态更新、保存重开，以及 1280／390／320px 下的笔记协作、截图和导出回归。
