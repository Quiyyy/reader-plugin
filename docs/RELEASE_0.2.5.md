# Reader 0.2.5 · 笔记主导航默认收起

编辑笔记时，最左侧的主导航图标栏默认隐藏，正文占用完整窗口宽度；窄窗口不再额外显示顶部全局导航条。左上角菜单按钮可展开主导航浮层，点击空白处、按 Esc 或切换页面后收起；返回编辑笔记时仍默认关闭。当前笔记目录继续使用阅读页同款目录按钮。

验证：16 项现有笔记目录、协作和工作台浏览器检查通过；独立页面检查覆盖 1280／390／320px 的默认收起、正文全宽、菜单浮层、Esc 焦点返回、空白处关闭和返回笔记后收起。截图与报告保留在本地 `artifacts/note-navigation-0.2.5/`。交付遵循 [Windows 单包流程](WINDOWS_DELIVERY.md)，原生 MCP 与模拟 AppBridge 检查不等于真实 Codex 窗口验收。
