# 0.2.14 原文批注与搜索定位

## 阅读与批注

- TXT、在线书籍、EPUB 和 PDF 的已有高亮可直接点击，打开对应批注；不修改原文节点或摘录锚点。
- 批注编辑不再使用遮罩模态框：宽屏显示在阅读区右侧，窄屏从底部展开。可编辑文字、选择颜色、移到回收站并撤销，也可将已保存的引用交给 Codex 或加入笔记。
- 未保存的批注会阻止离开阅读器或切换到另一条批注；关闭或 Esc 不会直接丢弃草稿，明确点击“取消”才放弃。版本冲突或保存失败时保留输入，不覆盖其他窗口的修改。

## 搜索与定位

- TXT 搜索支持同一段内的多处命中，正文高亮可通过“上一处／下一处匹配”连续跳转；结束查找后清除搜索高亮，已有批注保持不变。
- EPUB 本章查找支持跨行内元素匹配、命中高亮和连续跳转；PDF 支持当前页内的精确命中与连续跳转，已有跨页结果列表继续保留。
- 在书库或笔记列表搜索时，可按 Enter 或点击搜索按钮进入全文结果页。结果支持范围筛选、关键词高亮和文件夹路径，长笔记摘要围绕实际命中位置展示。
- 从全文原文结果打开 TXT、EPUB 或 PDF 时，进入命中位置并突出关键词。EPUB 仅在原文结构和文本可准确匹配时定位，否则明确提示继续查找，不猜测位置。

搜索定位使用已有内容和索引：TXT 单次最多 100 处结果，EPUB 阅读器查找限定当前章节，PDF 全局结果受已完成的文字索引限制；扫描页仍无 OCR。

## 其他修复与验证

- 整理菜单在滚动时跟随可见的触发按钮，避免刚打开就被排队中的滚动事件关闭。
- 拖拽测试等待进入文件夹的访问记录完成后再比较数据，保留“移动不改变访问时间”的校验。
- 隔离书库覆盖三种格式的批注、草稿保护、冲突、换色、删除与撤销，搜索跨章节／跨行内元素定位，以及原有书签和阅读进度回归。
