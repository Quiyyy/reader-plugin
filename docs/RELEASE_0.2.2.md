# Reader 0.2.2 · 精简界面与模型选择

2026-10-24。平台包以其 manifest 和来源提交为准，源码推送、包验收、本地安装及真实宿主 UI 是独立环节。

## 界面与行为

- 阅读对话默认允许按需读取当前书籍，移除“允许读取本书”勾选框。独立话题仍只使用所选引用，不自动获得其他书籍正文。
- 输入区提供模型入口，使用 Codex `model/list` 的真实目录。模型选择随话题保存，在新建、恢复会话及 `turn/start` 时应用；返回“默认模型”使用 Codex 当前配置。切换到不支持原推理强度的模型时使用该模型返回的默认强度。
- 移除聊天空白页的引导文字、重复话题标签、输入区缩放手柄和矩形焦点框。可操作控件保留无障碍名称与轻量键盘焦点下划线。
- 笔记不再显示来源数量／标签行或文件夹选择器。实际原文引用、正文、图片和已有标签／分类数据仍保留。
- 删除书库、笔记、添加菜单和书籍信息中的文件夹入口；显示所有未删除书籍与笔记。
- 精简找书、书源管理、导入和快捷键页面的重复常驻说明；保留错误、保存状态、删除确认和影响操作结果的信息。

模型接口依据 [OpenAI Docs · Codex App Server](https://learn.chatgpt.com/docs/app-server#list-models-modellist)，并核对本机官方 CLI。模型目录不是每次推理成功的保证；实际服务错误仍通过原有对话错误与重试流程处理。
