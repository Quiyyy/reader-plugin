# Reader 0.1.8

本版基于正式 0.1.7 / d7da13d，纳入已验收的 3bc0a57 功能候选与 77878bc 专项测试。版本、MCP 客户端/服务端标识及 UI 资源 URI 更新为 0.1.8，避免继续复用 0.1.7 缓存；依赖、QuickJS 隔离和 SafeHTTP 策略不变。

- 书架卡片和列表的更多菜单可将书籍移入回收站，支持撤销和恢复。原文、进度、书签和在线缓存作为同一可恢复状态保留；不永久删除，不联动删除书源。
- 正文默认 ↑↓ 滚动 80px、←→ 切换章节。书架方向键移动焦点、Enter 打开、Esc 返回或关闭 Reader 弹层。输入框、contenteditable 和中文组词保持原有方向键行为。
- 快捷键设置集中提供录制、重复/已知保留键校验、清除、恢复默认及持久化。宿主自定义冲突无法全部枚举；关闭快捷键默认未设置。
- 0.1.8 是首次支持 catalog 清单导入的客户端版本（源规则本身的最低兼容版本另计）。支持用户选择 `.reader-catalog.json` 清单包，核对版本、摘要、兼容性和差异后确认。新增/更新书源默认禁用，同版本同内容幂等、同版本不同内容拒绝；取消预览不写入。未知源不会自动导入、启用或订阅。
- 书源列表、启停、筛选、更多操作与折叠诊断保持原有结构。取消、首次滚动和启用后搜索焦点的相关竞态已修正。

## 数据与回退

书籍和在线记录仍采用 v1 格式。回收站是独立原子状态标记，不搬走原始文件或缓存；旧版本忽略标记时会重新显示这些保留的书籍。快捷键和清单回执为增量配置，保留覆盖前备份。详细恢复步骤见 [候选实现与数据说明](LIBRARY_KEYBOARD_CANDIDATE.md)。

升级前备份整个实际书库，Windows 默认 `%LOCALAPPDATA%\Reader`，显式配置的数据路径优先。保留旧安装与目录摘要，使用官方插件安装流程回退。不要用测试书库覆盖用户书库；验证安装包应指向独立数据目录。

## 验收与真实宿主边界

功能候选已通过 174 个单元测试、33 个浏览器用例、Mac/Windows/Linux CI，以及实际隔离安装的清单 UI、公开样章、进度/书签和进程重启验收。原创第二版清单专项覆盖预览、取消、确认、幂等、冲突拒绝、原书源和阅读状态保护。正式 0.1.8 分发仍必须由本次 main CI 的原生与远程安装门禁核准，不能沿用旧提交摘要冒充新包。

已核对公开 `window.openai.requestClose()` 和 MCP Apps `requestTeardown()`；显示模式不是关闭命令。Reader 只发出宿主请求，明确提示不支持/失败/请求已发送，不隐藏 iframe、不使用私有 RPC、不拦截宿主全局按键。**真实 ChatGPT 侧栏关闭尚未验证，关闭请求不保证成功。** Esc 仅操作 Reader 自己的界面。

维护书源独立版本化交付；仅已逐阶段验收的固定源可进入 ready 清单。清单静态校验不等于网站可读；候选源、超时来源不得借发布自动晋级。私有书源项目不随本次 Reader 发布转为公开。

现有 Mac 发布者签名/公证与正常目录限制保持不变。本次 Windows 升级不包含 Mac 客户端安装，也不重启整个 ChatGPT。
