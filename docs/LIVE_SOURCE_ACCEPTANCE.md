## 续查发现并修复的实际工程问题

1. **就爱文学省略 tbody。** 真实响应有 51 个 tr，原解析器不补隐含 tbody，固定规则选中 0 行。补齐有界表格结构后，同一份保存的响应在完全离线情况下恢复 50 行，逐条名称/作者/URL 可提取；后续另一公版书名的实际联网搜索也返回 50 行。没有改第三方规则。响应 SHA-256：`58b82586d2a3d09bc7d7e7741ea658eee7cbcbd74d82e4e2c99b289a4681a6f1`，见 `table-fix-offline-proof.json`。行为参考 [HTML 表格解析规范](https://html.spec.whatwg.org/multipage/parsing.html#parsing-main-intable)，仅补这一省略标签形式，不宣称完整 HTML5 解析。
2. **阅友详情的内嵌位图地址。** 41,108 字节页面里一个 img/src 的 data 图片地址长 25,698 字符，被旧的每属性 8 KiB 上限拒绝。现在仅为 img/src 的 PNG/JPEG/GIF/WebP base64 字面值允许至 64 KiB；不解码、不显示、不联网，SVG/主动 URI/其他属性仍保持 8 KiB。整个页面 2 MiB、节点/深度和输出上限不变。原始元数据页面离线重放后详情提取通过。
3. **阅友大目录的工作量误计。** 实际目录 465,219 字节、4,752 个元素、2,307 章，每个元素最多 3 个属性。旧代码每次读属性固定计作 128 项工作，导致合规目录过早耗尽预算。改为解析后缓存实际属性数并据此计费；仍共享原来的 2,000,000 工作量上限，重复扫描/平方级同级轴测试仍明确终止。同一真实目录离线重放后 2,307 章通过，未读取正文。
4. **网站提示页误计为空结果。** 独步返回 HTTP 200、1,531 字节、标题“提示信息”，没有 table/tbody/tr。此类明确的提示/错误标题且列表为空现在报告无法确认结果，不再记作搜索成功；普通“搜索结果”页面的空列表及 JSON 空数组仍允许。该站提示的具体原因尚未确定，不冒称登录、验证码或永久失效。
5. **实际目录 XPath。** 独立实现有界 `last()` 与 `following-sibling` 元素轴，支持大文学、思路客使用的目录形态；局部父节点位置、文档顺序、去重、输出/工作预算有原创测试。参考 [W3C XPath 1.0 位置与轴定义](https://www.w3.org/TR/1999/REC-xpath-19991116/)，未复用 GPL 实现。两源新增覆盖仅由静态检查及原创夹具证明，未联网验证。
