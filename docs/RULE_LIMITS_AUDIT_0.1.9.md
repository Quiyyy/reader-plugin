# 0.1.9 规则与资源限制审计

触发问题是正常长目录被固定 5 页限制拒绝。独立书源任务只读取目录，确认 9iwx 对应目录有 15 页、1453 条，末页正常终止，无重复章节 URL 或分页循环；正文请求为零。一次第 6 页超时后可续查。Reader 修复使用相同规则和原创目录验证，不批量请求该小说正文。

| 分类 | 处理 | 原因与实际行为 |
| --- | --- | --- |
| 目录、正文各 5 页 | 移除整本/整章的 5 页业务限制 | 每次最多处理 8 页，或到 20 秒后停止启动新页；保留完成页的续点。UI 显示“尚未完成”和继续按钮，重试接上原位置，服务重启后仍可续载。 |
| 单阶段 20 请求、8 MiB、操作 45 秒 | 保留为每批边界 | 不把大目录塞入单个无限长请求。每页的重定向、连接重试和规则内请求都计数；完成页不会重抓。单 HTTP 请求仍受 10 秒/2 MiB 保护和书源限速。 |
| 无限变化的分页 URL | 加强检测 | 规范化 URL、重定向目标、页内容指纹、目录无新增条目检测；多个相同下一页链接合并，多个不同下一页明确报规则错误。 |
| 分页跨批无累计边界 | 新增累计限制 | 总计最多 256 页、512 次连接、目录 32 MiB/单章 8 MiB 响应。触达后明确不完整，清除临时续点，不覆盖旧书、章节缓存或进度。 |
| 5000 章、整阶段 15000 次规则、500 次脚本 | 调整过窄限制 | 目录最多 20000 章；字段工作按页核算，分页脚本每页最多 15000 次。每批累计脚本执行时间仍最多 5 秒，由可信 Worker 使用单调时钟核算 guest 执行、宿主调用和结果序列化；IPC 排队、可信初始化和网络等待不误扣该额度。网络返回后仍扣剩余额度；不足一次 500 ms 的余额时在完成页边界暂停。每次脚本仍 500 ms 中断/2 秒强制终止；普通非分页阶段仍 500 次。 |
| 大量小脚本积累 WASM 内存 | 修复 Worker 生命周期 | 每页及每 128 次调用回收 Worker，只保留经过验证的变量；不扩大 16 MiB 软堆、32 MiB WASM 硬内存或 CPU/网络预算。原创回归曾复现旧实例的 memory access out of bounds。 |
| 搜索只允许前 5 页 | 移除 UI 的 5 页截断 | 用户一次只请求一页，可继续手动翻页；参数仍限定正整数到 10000，无自动整站遍历。搜索单页 200 条上限保留。 |
| 章节与重叠目录 | 保留完整性约束 | 目录按规范化 URL 去重并保留首次标题；单章最多 4 MiB/50000 段，不显示或缓存半章。目录刷新只在完整后替换，并核对稳定章节 ID、进度和书签。 |
| 临时续点存储 | 新增独立可丢弃缓存 | `online-v1/pagination-v1` 使用 v1 校验，按源修订/启停代数、书籍生命周期、操作和 URL 隔离；原子写入。最多 16 个、64 MiB，单个 16 MiB，24 小时过期。取消只保留完整页，不标为完整书籍。 |

## 必须保留的安全边界

SafeHTTP 的公网地址与 DNS 全答案检查、IP 固定、TLS 校验、禁止 HTTPS 降级、标准端口及显式 origin 集合保持不变。登录、真实挑战、付费授权等访问限制不会被移除；cookie、认证头、私网和任意网络能力不会交给脚本。QuickJS 与主进程隔离，不开放 Node、文件、进程或动态下载代码。正则使用有界 RE2；DOM 深度、节点数、同步工作、输入输出大小限制继续阻止恶意规则与页面耗尽资源。

EPUB 的 ZIP 路径、解压、大小、DRM 和实体边界保持；只修复无内部子集的惰性 DOCTYPE 被误拒。HTTP 单页压缩响应、未实现的 Jsoup/浏览器 API、URL 片段区分章节等兼容范围仍明确不支持，不能为让格式检测通过而声称可读。清单导入仍核对摘要、版本和差异，默认停用新增或更新源。

## 数据兼容和验证边界

已有书籍、缓存、设置和书源记录不迁移。新增续点是独立临时状态，可以在备份后丢弃并重新加载，不应拿它覆盖书库。0.1.9 的 Windows/Mac/Linux 使用相同格式。若回退到 0.1.8，其 5000 章校验不认识后来新增的超长目录；须先完整备份，再将这些新记录单独保留在回退书库之外，不能直接用旧快照覆盖升级后进度。

针对性测试覆盖 8000 章/40 页、目录重叠去重、进程重启、17 页原创单章、失败页重试、原目录/缓存/进度/书签保护、循环和累计上限、脚本状态以及源代数变化。独立书源任务的原创 15 页/1453 条、25 页/2423 条和 6 页循环样例补充同规则复现。320/390/1280 截图及键盘续载使用测试宿主，不能代替真实 ChatGPT 面板关闭验收。
