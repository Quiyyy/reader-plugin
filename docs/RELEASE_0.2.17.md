# 0.2.17：统一设置与内容操作

设置由独立外观弹窗改为完整页面，提供分类导航、搜索与统一的配置行。常规、外观、阅读、笔记、Note Bots、快捷键、书源、数据与关于都从同一入口管理；阅读器、笔记和对话中的快捷入口进入对应分类。窄屏保留相同导航结构，折叠分类文字。

一般设置自动保存，失败可重试；未保存完成时阻止返回。Note Bots 继续使用明确的保存按钮，并保留未提交的表单草稿。底层阅读器与笔记保持挂载，返回时恢复原内容和位置。默认书库排序、笔记模式与工具栏偏好随书库持久化，兼容之前的本机偏好。

笔记块手柄使用 14px 六点图标，保留拖动排序；点击可提出 AI 修改要求、上下移动、创建副本或删除。文档修改接入编辑器历史，可撤销；仅打开菜单不会改写正文。

阅读重排使用内容锚点。TXT 与在线正文不再仅保留旧的滚动像素；EPUB 翻页后的程序滚动不再覆盖重排前的文字位置，避免连续改变宽度时向章节开头漂移。

## 验证范围

回归覆盖设置保存及失败重试、返回后的笔记与阅读状态、320／390／1280px 布局、Note Bots、书源导入、快捷键、块操作与撤销、TXT 和 EPUB 连续缩放。发布前按仓库 Windows 单包流程验收原生包、安装与数据完整性；独立浏览器和模拟 AppBridge 的检查不等于实际宿主页面验收。
