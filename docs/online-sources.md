# Legado 书源兼容（0.1.7 候选）

Reader 通过本地服务读取用户有权访问的公开文本，按章缓存，不自动搜集第三方书源或下载全书。完整技术边界、固定 22 源差异与已知阻碍见 [隔离兼容说明](ISOLATED_COMPATIBILITY.md)。

## 导入和阅读

1. 在「找书 → 管理书源 → 导入书源」选择 UTF-8 JSON 文件或公开 JSON 链接；支持单对象/数组，每批 1–50 源、512 KiB，总量 100 源。
2. 核对名称、域名、可尝试搜索数量和变更摘要。若列出额外网络域名，请逐项检查；技术详情按搜索/详情/目录/正文列出诊断。
3. 确认导入后单独启用来源，再搜索、查看详情、加入书架。只检查格式不等于已能阅读。
4. 页面和章节在需要时请求；目录和正文按最多 8 页/约 20 秒分批加载，可跨服务重启续载；目录最多 20000 章，累计页数、请求和字节均有上限。不完整目录或章节不会当作成功结果保存。详见 [0.1.9 限制审计](RULE_LIMITS_AUDIT_0.1.9.md)。
5. 已成功缓存的章节可离线打开。进度和书签依赖稳定章节 ID，停用来源、失败刷新或修改书源不会覆盖旧进度/缓存；源修订变化后需重新搜索添加，旧缓存保留。

书源管理保留名称/域名搜索、状态筛选、逐项启停、详情展开、移除确认与键盘操作。规则字段较多的源仍以紧凑列表显示。来源更新会默认停用并展示差异。TXT/EPUB 使用原有独立数据格式，不迁移或覆盖用户书库。

## 能力范围

- 有界 CSS/经典选择器、正负和排除索引、倒序闭区间切片、children、文本定位、部分属性条件和 XPath；文本/属性、ownText/textNodes/纯文本 HTML。
- JSONPath 属性、索引、数组通配；组合 `&&`、回退 `||`、显式 CSS 逗号组合。XPath 支持元素路径、相等条件、`last()` 和 `following-sibling` 元素轴；其他轴、表达式和递归 JSONPath 仍须看字段诊断。
- `##正则##替换` 使用有限 RE2，支持 `$0`–`$9` 捕获替换和小型有限计数；正文模板变量以正则字面量转义，不允许反向引用、环视、无限编译展开或输出请求选项。
- UTF-8、GBK/GB2312/GB18030 请求参数、GET/表单 POST、静态非身份头和按源请求频率；响应字符集独立解码。
- 隔离 JS 规则链、URL/字段表达式、详情 init，以及常用 java 变量/提取/编码/受控 ajax。JS 可被识别不保证其调用的每个 Legado 宿主 API 已实现；实际步骤会给出错误。
- 发现、展示、未用登录入口等声明单独提示，不因它们含脚本而全局阻止。实际内容依赖的未知规则不会被截断跳过。

## 网络与脚本安全

默认仅源 origin；可选 `readerAllowedOrigins` 明确列出最多 8 个额外 origin，导入预览可见、启用前须核对。不推断子域、不接受通配域。只允许公开 HTTP 80/HTTPS 443，无 URL 凭据；拒绝私网、回环、元数据和混合 DNS 回答。每次连接固定已校验 IP，保留原主机 Host/SNI/TLS；重定向、重试、ajax 同样受限，不允许 HTTPS 降级。

单次请求 10 秒/2 MiB/最多 3 跳，最多 4 个 HTTP 请求和 16 个等待；仍拒绝压缩炸弹风险响应。源频率声明在每次实际连接前执行，POST 不自动重试。操作去重、取消和来源修订检查保持；过期结果不写入书库。

源内脚本只在 QuickJS WebAssembly Worker 执行。无 Node eval/vm、文件、环境变量或 process 入口，禁止动态代码导入/编译。脚本堆、WASM 总内存、栈、CPU、输出、变量、网络数量与字节分别有上限；父服务可强制终止 Worker。具体数值、上游缺陷防护与测试见 [隔离兼容说明](ISOLATED_COMPATIBILITY.md#隔离与边界)。

Cookie、Authorization 和身份类请求头仍拒绝。没有登录账号、持久 Cookie、验证码、付费或 DRM 绕过能力。`startBrowserAwait`/WebView 需要真实宿主浏览器会话，目前明确停止；fetch 不被包装成浏览器。

## 验证和状态

规则状态与联网状态分开。`supported/partial` 表示可尝试相应阶段；`blocked/invalid` 说明当前不能执行。`untested/passed/failed` 分别是尚未联网、最近阶段完成、最近阶段失败。空搜索列表可能是无结果或站点结构变化，不能证明正文能读。

`tests/online-isolated.test.ts` 以原创页面验证 GBK 实际字节、JS 链、变量作用域、分页、书签、进度、真实进程重启/离线缓存，以及 SSRF、域策略、网络配额、OOM/死循环/正则/恶意输出/取消。原有声明式、DOM/JSON 预算、HTTP 和 UI 回归继续覆盖 TXT/EPUB 和书源管理。

可导入的原创联网样例：[`reader-script-cdn.json`](../examples/online/reader-script-cdn.json)。它只读取本仓库已发布的原创页面，不读取第三方小说文本；静态基准审计、三个匿名公开搜索探测和原创完整联网探测由 `scripts/audit-source-capabilities.mjs`、`scripts/probe-public-sources.mjs`、`scripts/probe-original-script.mjs` 分开生成证据。最终是否可统一升级，还须同一提交的完整检查与六平台候选验收。
