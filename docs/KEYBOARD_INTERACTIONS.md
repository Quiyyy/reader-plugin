# Reader 键盘交互

## `@` 插入与指派

笔记正文的排版、源码模式以及底部对话输入框使用同一套候选面板。

- **Bots**：按名称或用途筛选，默认 Bot 优先。选择后指派助手，等待用户输入并发送任务。
- **引用**：选择书中已有摘录。在正文中插入可回到原文的引用标签；在对话中作为本次任务的上下文，最多 8 条，并随草稿保存。
- **日期**：插入今天、明天或昨天的本地日期。

`↑`／`↓` 切换候选，`Tab`／`Enter` 确认。首项按 `↑` 可进入分类栏，`←`／`→` 切换分类，`↓` 返回候选。`Shift+Tab` 关闭面板并退回前一个控件。没有选中候选时，`Enter` 不会发送任务，`Tab` 关闭面板并继续页面焦点顺序。

`Esc` 关闭面板并保留已经输入的 `@` 文字；继续输入时可作为普通文字。邮件地址、网址及 Markdown 代码中的 `@` 不展开候选。输入法组合期间的确认、取消和方向键交给输入法处理。

## 弹层与焦点

| 场景 | `Tab` / `Shift+Tab` | `Esc` |
| --- | --- | --- |
| 新建、整理、块操作、附件、模型、对话历史菜单 | 关闭菜单，从打开按钮继续前后移动焦点 | 仅关闭此菜单，回到打开按钮 |
| 模态对话框 | 在当前对话框的有效控件之间循环 | 取消当前对话框，沿用保存中的关闭保护 |
| 原生下拉选项 | 保留浏览器原生选择行为 | 先关闭下拉选项 |
| 笔记评论 | 按页面顺序移动 | 关闭评论面板，回到笔记；本次编辑期间同一选区的未提交评论仍保留 |
| 阅读目录、搜索等面板 | 保留面板的控件顺序 | 先关闭面板，再次按键才执行阅读页返回 |

菜单内支持方向键与 `Home`／`End`，通过 `Enter`／空格执行已聚焦的操作。关闭内层菜单不会同时关闭外层设置或对话；焦点恢复不会主动滚动阅读位置。切换控件和关闭候选不会自动提交 AI 任务。
