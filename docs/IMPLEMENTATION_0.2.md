# Reader 学习工作台开发记录

依据：`docs/design/reader-workspace/PRODUCT_DESIGN.md`。用户已授权开发正式版本，后续根据实际使用调整细节。

## 已确认范围

- 保留 TXT、结构化 EPUB、在线阅读和旧书库。
- 笔记、三层文件夹、标签、批注、稳定引用、统一搜索与回收站。
- PDF 页面、文字与区域选择、来源回跳，密码在会话内使用。
- 可配置强调色、明暗与纸色，图标提示代替常驻说明。
- 独立阅读会话浮窗，官方 Codex app-server stdio，多轮与恢复；原生交接保留。
- 通过 MCP 暴露有范围的数据读取和笔记／批注／组织操作。
- Space 为可选的原生对话交接，不伪造 Page 写入成功。

## 实施顺序

1. 共享契约与独立持久化，版本检查、可撤销修改和引用校验。
2. PDF 适配与资源服务。
3. 工作台 UI、笔记编辑、批注及来源跳转。
4. Codex 子进程会话与浮窗。
5. 协议工具、分发资源、测试与隔离 UI 验收。

## 验证边界

只使用原创测试样本和独立 `READER_DATA_DIR`。不覆盖正式安装或真实书库。实现结束后验证旧功能、真实数据重启恢复、新界面和协议；真实宿主与实机 Codex 生成分别记实测结果。

## 当前进度

正式功能开发完成。实现范围、启动方法、验收证据与宿主边界见 [0.2.0 说明](RELEASE_0.2.0.md)。

- 304 项单元／协议测试和 5 项原生平台测试通过；TypeScript、构建和插件校验通过。
- 全量浏览器回归 45/45，包含追加的 opaque iframe PDF 场景。
- 真实 Codex 选区问答、连续追问、工具创建笔记和重连恢复通过。
- 原生 MCP／模拟 AppBridge 验收通过；真实 Codex 插件安装界面、Space 与原生下载仍需安装后体验验收。
- 本地运行包已验证不依赖可选 native canvas，清空 PATH 后仍能解析 PDF 并重启恢复。
- 正式 UI 的独立示例预览使用 scripts/preview-workspace.mjs，设计原型继续保留；未覆盖真实书库或当前插件安装。
