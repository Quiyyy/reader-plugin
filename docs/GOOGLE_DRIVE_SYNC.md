# Google Drive 多电脑同步

Reader 0.3.0 提供可选的 Google Drive 同步。先保存到本机，联网后交换独立条目的版本；断网仍可阅读和编辑。适用于同一用户的多台电脑，不提供多人实时协作。

## 创建 Google 桌面客户端

1. 在 [Google Cloud Console](https://console.cloud.google.com/) 创建或选择项目，在“API 和服务 → 库”启用 **Google Drive API**。
2. 打开 **Google Auth Platform → Branding**，填写应用名称、支持邮箱及开发者邮箱。
3. 在 **Audience** 选择 External（个人 Google 账户），开发时使用 Testing，将自己的 Google 邮箱加入 Test users。
4. 在 **Data Access** 添加 `https://www.googleapis.com/auth/drive.appdata`。Reader 还请求 `openid` 与 `email` 识别当前账户，不请求整盘访问权限。
5. 在 **Clients → Create client** 选择 **Desktop app**，填写名称，下载 JSON。不要选择 Web application，不需要手填网页重定向 URL。
6. 将 JSON 保存到仓库和网盘同步目录之外，例如 Windows 的 `C:\Users\你的用户名\ReaderCredentials\google-desktop.json`。不要将文件、刷新令牌或恢复密钥提交到 Git。

所有电脑应导入**同一个项目的同一个桌面客户端 JSON**，并登录同一 Google 账户。不同应用的隐藏数据空间不互通，不能在每台电脑分别新建不同项目后期待看到同一书库。Reader 不复用 Codex 的 Google Drive 插件登录。

官方说明：[创建客户端](https://developers.google.com/workspace/guides/create-credentials)、[同意屏幕](https://developers.google.com/workspace/guides/configure-oauth-consent)、[桌面授权与本地回调](https://developers.google.com/identity/protocols/oauth2/native-app)。External + Testing 状态下，包含 Drive 范围的刷新令牌通常在 **7 天**后过期；届时在 Reader 重新授权。长期使用应按 Google 的要求发布应用并满足对应验证要求，不能通过 Reader 绕过。[令牌有效期](https://developers.google.com/identity/protocols/oauth2)

## 第一台电脑

1. 打开“设置 → 同步”，导入客户端 JSON，点击“连接 Google Drive”。
2. 在系统浏览器完成 Google 授权，然后返回 Reader。授权使用 PKCE、随机 state 和 `127.0.0.1` 的临时回调端口。
3. 填写书库名、此电脑名称和同步范围，点击“创建并同步”。开启后，会上传所选范围内的现有本地内容。
4. 复制或保存**恢复密钥**，另行保存在安全位置。Google 登录与书库解密是两个步骤；丢失全部本机凭据及恢复密钥后，无法从云端解密书库。

## 另一台电脑

1. 安装同版本 Reader，导入同一客户端 JSON，并授权同一 Google 账户。
2. 选择“连接已有书库”，输入恢复密钥，设置不同的电脑名称。
3. 笔记和书目合并到本地；点击有云端标志的书籍时才下载原文件。PDF 如需密码，在此电脑重新输入。

连接前可先备份两台电脑的本地书库。已有本地条目参与合并，不会把一台电脑的整份数据库覆盖到另一台电脑。

## 同步范围与时机

| 数据 | 行为 |
| --- | --- |
| 笔记、评论、文件夹、引用、批注、书目元数据 | 默认同步；笔记图片按需下载 |
| Note Bots | 同步名称、指令、模型选择及默认 Bot；模型是否可用取决于每台电脑的 Codex 配置 |
| 书签、阅读位置 | 默认同步；分别保留各设备位置，在设置中明确选择下次打开的位置 |
| TXT／EPUB／PDF 原文件 | 默认开启，可关闭；另一台电脑打开时下载，沿用原导入大小与格式限制 |
| 在线书籍 | 同步书目、书签与位置；每台电脑需自行添加相同书源和书籍，书源配置及章节缓存不传输 |
| 外观、笔记偏好、快捷键 | 可选，默认关闭 |
| AI 对话、运行中的任务、本机授权范围、最近访问顺序 | 保留在本机 |
| OAuth 凭据、Codex 登录、PDF 密码、书源凭据、解析缓存 | 不上传 |

首次下载书籍时，如果只有一个可用设备位置，会恢复该位置。已有本地书籍不会被另一台设备的阅读进度不断跳转；在“其他设备的阅读位置”中按需选择。

自动同步由**打开的 Reader 页面**触发：工作台修改约 1.8 秒后、恢复前台时，以及约每 45 秒一次。支持“立即同步”、暂停和断开。正常关闭时，在本地保存后短暂尝试完成同步；断网或强制关闭后，已保存修改会在下次同步时重新扫描、补发。不安装常驻后台服务，也不创建 Codex 定时任务。

断开账户保留本地内容和书库关联；重新授权后可恢复。更换书库保留本地内容，但会解除当前云书库关联。范围切换需先完成已排队上传，暂停和断开不受此限制。

## 冲突、删除与恢复

- 不同笔记的离线修改自动合并。同一条目存在分叉时保留双方版本，不按时间戳直接覆盖正文。
- “设置 → 同步 → 需要处理的冲突”提供版本比较与选择；笔记支持“保留两个版本”。再次发生修改时需重新查看版本。
- 删除与编辑同时发生会保留冲突。正在打开的笔记被其他电脑删除时，编辑器仍保留本机草稿，可明确恢复并保存。
- 移入回收站、恢复和逻辑删除会同步。云端记录意外丢失、账户失效或数据校验失败时停止同步并保留本地内容，不把空云目录当作清空本地书库的命令。
- **当前版本保留不可变同步历史及附件，没有自动历史清理。**“永久删除”移除当前条目及本机相关文件，不等于抹除所有云端历史或其他设备副本。另一台电脑的原书可能仍保留在其回收站。若要清除所有副本，需分别管理设备备份和 Google 的应用数据；删除应用数据会影响整个同步书库。
- 同步不是独立备份。关闭或暂停后备份完整本地书库，同时另行保存恢复密钥。操作系统凭据不在书库备份中。

## 数据与加密

云数据使用 Google Drive 的隐藏 `appDataFolder`，不会在普通“我的云端硬盘”列表显示，也不使用 Drive 回收站。书库内容和附件以 AES-256-GCM 加密后传输，校验值与对象标识用于检查完整性；Google 仍可见对象数量、大小和访问时间。加密设计未经独立密码学审计。[应用数据说明](https://developers.google.com/workspace/drive/api/guides/appdata)

OAuth 刷新令牌、设备身份和解密密钥使用操作系统安全存储：Windows 使用当前用户 DPAPI，macOS 使用 Keychain，Linux 需要 `secret-tool` 和可用的 Secret Service。Windows 的加密凭据位于 `%LOCALAPPDATA%\ReaderCredentials`；不要把该目录当作跨电脑可移植的凭据备份。本轮实际验证了 Windows DPAPI，macOS／Linux 安全存储仍需各平台实机验证。

本地 `sync-v1` 保存索引、版本历史与传输队列，现有书库本身仍是本机明文存储。当前索引上限 128 MiB、版本记录上限 50,000，尚无历史压缩／垃圾回收；达到限制会停止同步并提示备份，不删除用户内容。

## 验证范围

自动化覆盖两个隔离本地书库的离线分叉、删除与编辑冲突、独立条目合并、原文件按需下载、TXT／EPUB／PDF 定位、草稿保留、云端记录损坏、上传中断重试、OAuth state／PKCE、取消授权及 Windows DPAPI。浏览器测试验证统一设置和窄屏布局。

自动化传输测试使用可控的模拟响应。2026-10-31 另行完成真实 Google 账户联调：在同一台 Windows 电脑上使用两个独立设备身份和隔离书库，通过实际 `appDataFolder` 验证加密上传、恢复密钥加入、笔记拉取、TXT 按需下载、图片校验、书签与阅读位置，以及并发修改后保留两个版本。使用的 8 个原创测试云对象已全部删除，没有上传个人书库。

该联调不等于不同物理电脑或所有操作系统的实机验收；长期令牌续期、大文件断网续传、限流和各平台安全存储仍需对应环境验证。首次使用仍需完成个人 OAuth 配置及 Google 授权，连接账户本身不会自动创建同步书库或上传个人内容。
