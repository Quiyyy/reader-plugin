# 使用指南

本文面向 0.2.12。已分发插件可能仍处于较早版本；安装方式见 [安装指南](INSTALL.md)。

## 书库与阅读

点击“新建”，可创建笔记本或文件夹、导入书籍，也可进入在线找书。文件支持 TXT、无 DRM EPUB 和 PDF，文本编码在“导入选项”中设置。已导入文件按原始内容去重；同名但内容不同的书可以共存。书源规则范围见 [在线书源说明](online-sources.md)。

书库将文件夹、书籍和笔记本放在同一封面网格中，默认按最近访问排序，也可按名称排序或直接切换网格／列表。点击封面或名称打开条目，点击名称旁的“…”进行重命名或移动；书籍的“书籍信息”还可修改标签或移入回收站。搜索只筛选当前文件夹。

文件夹沿用已有分类数据，最多支持三层。进入文件夹后可用上方路径返回；从阅读器或笔记编辑器返回时保留原文件夹。新建笔记本和新导入书籍放入当前文件夹。“选择”模式可一次移动书籍、笔记本及文件夹；有版本冲突、循环目录或同名文件夹时整组操作不会部分保存，成功后可以撤销。

使用鼠标拖动封面到目标文件夹，目标高亮后松开即可移动；也可拖到上方路径或返回按钮，移回根目录或父目录。“选择”模式下，拖动任一已选条目会移动整组选中内容。按 Esc 可取消拖拽；无法投放到自身、当前目录或会造成循环／超出层级的目录。键盘与触屏可继续使用“选择 → 移动”。外部文件拖入书库仍按当前文件夹导入。

最近访问记录单独保存，不修改笔记正文版本，也不与更新时间混用。旧笔记和文件夹没有访问记录时不显示时间，首次打开后开始记录；已有书籍在首次记录前沿用原有阅读时间。重命名、移动和内容编辑不刷新访问时间。

阅读器自动保存已确认的阅读位置。TXT 和在线书籍支持段落书签；EPUB 保留结构化目录、图片、表格和脚注。PDF 提供目录、页码、缩放、旋转及页内查找。窗口较窄时，一部分工具入口会收起到菜单或抽屉中；悬停图标可查看名称。

## 摘录、批注与笔记

划选文字后，使用选区工具条高亮、批注、加入笔记或向 Codex 提问。PDF 图表可通过“框选区域”保存为图片摘录。

笔记支持 Markdown 正文、图片与独立引用。旧笔记的标签和分类仍保存，但不再占据编辑界面。点击来源的“回到原文”可查看原书位置，再返回笔记；查看来源不会覆盖普通阅读进度。原书进入回收站后，已保存摘录和截图仍然保留，来源会提示暂不可用。

书库中的笔记本沿用现有笔记文档及编辑器，以正文或图片缩略图展示；笔记页和阅读侧栏保留紧凑列表。首页不再设置独立的续读、阅读状态分组或最近笔记区域。各页面继续精简非必要说明，保留操作名称、错误诊断、引用内容和保存状态。

编辑笔记时，最左侧主导航默认隐藏，可由左上角菜单按钮展开；点击空白处或按 Esc 收起。笔记顶部使用与阅读页相同的目录图标，默认收起。目录只列出当前笔记的 Markdown 标题，点击可在编辑或预览模式定位；不会显示全部笔记。正文随窗口与内容增长。截图可以直接粘贴、拖入或通过图片按钮插入。

点击“Codex 辅助编写”可让助手处理当前笔记，也可以从截图旁启动标注。对话输入区可附图。支持矩形、箭头、高亮与文字标注，原图保留；导出时包含带标注的图片。

编辑会自动保存。若另一个窗口或 Codex 更新了同一篇笔记，编辑器保留当前草稿并提示比较版本，不直接覆盖。看到保存失败时，可重试或复制保留草稿。

笔记操作菜单提供导出：纯文字导出 `.md`；含图片时导出 `.zip`，其中包括 Markdown、图片及来源 JSON。

## 与 Codex 讨论

普通阅读与笔记不依赖模型。浮窗使用独立的官方 Codex app-server 会话，需要本机官方 Codex CLI 可启动并已登录；它不会复用桌面私有通信接口。

1. 从选区选择“问 Codex”，点击阅读工具栏的对话图标，或从笔记选择“Codex 辅助编写”。
2. 按需从输入区下方选择模型，确认引用并输入问题，按 Enter 发送；Shift+Enter 换行。
3. 在同一话题继续追问。浮窗可以拖动、收起或关闭，历史与草稿仍保留。
4. 用回答下方的笔记图标保存内容和来源；长时间回复可停止。

阅读对话默认可按需读取当前书籍，其他书籍不在本次范围内。没有绑定书籍的独立话题只使用已提供的引用。模型选择随话题保存；“默认模型”使用 Codex 的当前配置，切换模型不会扩大阅读范围。

找不到 Codex 时，先检查官方 CLI 安装和登录。可设置 `READER_CODEX_PATH` 为可执行文件或官方 `codex.js` 的绝对路径，之后重启 Reader 服务。Windows 使用 `.exe` 或官方 JavaScript 入口，不将 `.ps1` 路径作为该配置。插件模式下，应通过宿主支持的启动配置传递环境变量；终端变量不会自动进入已经运行的桌面进程。

所有 Reader MCP 操作默认只供插件 UI 使用。内部对话才按当前笔记或书籍注入对应操作；普通原生对话不会默认获得 Reader 工具。需要在原生对话继续时，主动使用内容交接入口。

## 整理到 Space

在笔记工具栏选择“整理到 Space”，指定已有 Page 或新建私人 Page，向原生 Codex 对话发送整理请求。原生对话需具有可用的 Space 能力，完成后返回 Page 链接；Reader 不要求原生对话调用隐藏工具或自动写回关联。

独立浏览器预览没有原生消息接口时，提供可复制的交接内容。Reader 不直接内嵌原生 Space 编辑器，也不自动双向同步；本地笔记仍为权威版本。

## 外观与快捷键

书库的“外观”中可设置明暗、强调色和纸色。TXT、在线书籍和 EPUB 阅读界面上方只保留右侧的“阅读样式”或“阅读外观”，用于调整相应阅读器的样式；PDF 保留其唯一的“界面外观”入口。快捷键可在“键盘快捷键”中查看和修改；输入框内的按键不会触发阅读导航。

## 数据与备份

书库由 Reader 服务保存，原始文件与笔记不存放在插件运行缓存里。设置 `READER_DATA_DIR` 可覆盖默认位置；默认目录见 [README](../README.md#数据与权限)。

等待保存完成并关闭 Reader 后，备份**整个书库目录**，这样才能同时保留原始书籍、阅读进度、书签、设置、笔记、批注、图片、引用和阅读对话。预览的数据目录记录在 `artifacts/workspace-preview/latest.json`，不要把它与日常书库混用。

主动提问时，所选文本、图片、问题以及允许工具读取的资料会传给配置的模型服务。在线阅读会请求已启用的书源；离线阅读已缓存内容不下载全书。Space 整理由用户主动发起。Reader 不额外加密本地书库，请按自己的设备和备份需求管理数据。

“移到回收站”可恢复。永久删除会移除相应本地原书或条目，但不会自动清除独立摘录、导出副本和用户备份。恢复旧程序版本也不会恢复书库快照。

## 格式与容量

| 内容 | 当前范围 |
| --- | --- |
| TXT／EPUB 导入 | 单文件不超过 32 MiB |
| PDF 导入 | 单文件不超过 64 MiB、10000 页 |
| 扫描 PDF | 阅读与截图；尚无 OCR |
| PDF 搜索 | 已索引页文字；加密 PDF 不持久保存解密文字索引 |
| 单篇笔记 | 50 万字符 |
| 工作台元数据 | 48 MiB；最多 2000 篇笔记，保留旧分类元数据 |

EPUB CSS、CFI、固定版式等限制见 [格式说明](EPUB_CANDIDATE.md)。遇到问题时请附版本、环境和原创的最小复现材料，参阅 [贡献指南](../CONTRIBUTING.md)。
