# Reader 设计原型验证记录

本记录只覆盖设计原型阶段；后续正式功能与真实 Codex 验证见 [0.2.0 说明](../../RELEASE_0.2.0.md)。

验证日期：2026 年 10 月 12 日。环境：Windows，本机 Microsoft Edge，无头浏览器。

## 已通过

- 生产 Reader 采用真实原生 MCP 服务与模拟 AppBridge，独立书库、原创 EPUB；正文、目录锚点、图片放大、字体、表格、脚注返回、进度与书签恢复通过现有检查。
- 原型支持创建文件夹并移动书籍，书籍身份与来源关系保持不变。
- 完成文字选择、批注、带来源的新笔记、编辑保存、原文回跳；返回笔记后保留文字选择位置。
- 保存失败时保留草稿，刷新后可恢复，重试可成功保存。
- 来源缺失与宿主不可用分别提供恢复和可复制上下文。
- PDF 示意画布中的实际拖选区域被裁剪为图片，并带页码存入笔记。
- 搜索展示书籍、笔记与批注结果。
- 320px、390px 下的书库、阅读、PDF、笔记、搜索均无页面水平溢出；学习面板可开关。
- 浮窗支持两轮连续演示追问、拖动、收起、话题切换、关闭重开和草稿保留，前后正文宽度不变；回答可保存为有来源的笔记。
- 浮窗与输入框在 320px、390px 内可用，不超出视口。
- 自定义强调色和明暗模式刷新后保留；取消预览恢复旧值。颜色输入、纸色和预设可以交互。
- 图标悬停显示名称，Esc 关闭提示；纯图标按钮保留无障碍名称。
- 图文文档已渲染，10 张内文图片引用存在；截图已人工查看。
- 浏览器记录无未捕获页面错误、无外部网络请求。
- 静态服务器拒绝写入方法、越界文件请求与外部 Origin。

## 界限

原型不是生产功能交付。未读取真实用户书籍、未调用模型、未访问或修改 Space，未修改正式插件安装或数据目录。

真实 Codex 持续会话、登录、流式回复、Reader 工具调用、原生对话交接、Page 写入回执与多客户端行为尚未验收。现有 AppBridge 检查与本地布局原型各自覆盖相应范围，不互相替代。

首期产品文档中的跨版本引用恢复、并发编辑冲突、批量操作、真正的 PDF 解析和 OCR，均不是本轮浏览器检查已完成的功能。
