## 复现与原因

用户指定的 XIU2/Yuedu `shuyuan` 固定在提交 `426b24f59aa763ee0f2d9cc094612d2ef42c8293`，共 22 个来源、163824 字节，SHA-256 为 `00644eda44f0fcabcfc015a024480376638d5e7a381a2010aeedfca5aa797845`。只读取其 JSON，不执行其中脚本，不访问其小说网站。原始集合与用户截图均保存在仓库外，不随源码、测试或发行包传播。

0.1.6 对全部 22 个来源的 `ruleExplore` 都产生源级阻断，并传播到搜索、详情、目录、正文四阶段。这是“全部不兼容”的共同原因；不是书源文件之间发生冲突。另有未使用的搜索简介/检查关键词/下载字段、纯文本 HTML、裸输出、XPath、索引、正则清理和 POST 字面量语法缺口。源内任一字符串出现 `js` 并不能证明四阶段都依赖脚本。

本次把明确未使用的发现、展示和下载字段整体忽略并列出诊断，实际消费的字段仍逐个完整编译。含 JS 的正文、搜索地址、初始化、VIP/卷规则、WebView 选项等仍阻止其依赖阶段。来源声明的登录/自定义请求头配置仍保守阻断；没有以无视访问配置为由宣称兼容。

## 实现与验证边界

新增规则的精确定义、预算和网络边界见 [online-sources.md](online-sources.md)。GET/POST 共用原有 DNS 全地址检查、连接 pinning、Host/SNI/TLS、同源跳转、字节、排队、超时与取消限制。POST 只接受不求值的字符串字面量搜索表单，不接受 Cookie、Authorization、用户身份请求头或任意方法，也不自动重试 POST。没有 WebView、验证码、登录、付费/DRM 绕过。

原创最小样例在 `tests/online/declarative.ts`。测试覆盖：导入不联网；忽略字段中的脚本不执行；POST 编码与重定向方法；相对链接；XPath、负索引、排除索引、children、文本定位；HTML 仅作纯文本；正则清理及 Unicode；两页目录与正文；按章加载；新服务实例及真实服务器子进程重启；进度/书签恢复；离线缓存零请求。全程使用明确注入的本机测试 transport，没有新增生产网络例外。

浏览器用 320、390、1280 三种宽度验证导入、紧凑来源管理、状态详情、阅读和恢复，并输出原创样例截图。界面显示“待验证”“仅能尝试搜索”“暂不支持”和实际网络结果，不把保存成功当作读取成功。真实 ChatGPT 原生入口以及候选安装仍由发布方后续验收。

依赖新增 `re2js@2.8.6`（MIT），无原生编译或安装脚本；锁文件固定版本和完整性。已核对正式 0.1.6 的锁文件：`vite-plugin-singlefile@2.3.3 → micromatch@4.0.8 → braces@3.0.3` 全部是既有开发依赖，3 个高危条目归于同一 [braces 公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)，运行包中不包含它们。上游暂无修复版本，未采用 npm 建议的不兼容旧主版本降级。候选移除了整条依赖链，以项目内 `scripts/inline-ui.mjs` 对唯一 HTML 入口做有限内联，拒绝未知或外部资源；不支持可配置 glob，也未新增第三方包。新构建、资源校验、HTML 逃逸回归和完整 UI 回归共同验证替代步骤。完整/生产 npm audit 均为 0 项。

参考仅用于格式/引擎行为核对：[XIU2/Yuedu](https://github.com/XIU2/Yuedu)、[Legado 文档](https://gedoor.github.io/docs/GettingStarted)、[RE2JS](https://github.com/le0pard/re2js)。没有复制 GPL 规则引擎实现或第三方源集合。

本机候选验证：`npm run check` 通过（152 单元测试；平台 4 通过、1 个 Windows 专属用例跳过），完整 `npm run test:e2e` 27 通过，生产依赖 `npm audit --omit=dev` 0 项。内存回归包含 128 MiB 子进程中 200 个不同正则及原有 5000 层 DOM 攻击样例。以上不替代六平台发行 CI 或真实网站的合法联网验证。
