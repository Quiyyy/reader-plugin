# 0.2.13 整理与阅读体验

本版保留紧凑的文件夹、书籍、笔记混排书库，默认按最近访问排序；不新增独立续读条、格式标签或条目数量说明。

## 改动

- 书库搜索覆盖当前文件夹及其子目录，跨目录结果显示路径；清空搜索后恢复当前目录列表。
- 条目菜单支持直接移到回收站；选择模式支持全选和 Esc 退出。文件夹默认保留内容到上一级，单个文件夹也可选择连同内容回收。回收站可恢复文件夹。
- 单项回收提供撤销；批量回收逐项执行，失败时明确显示已完成部分，已回收条目可从回收站恢复。
- 封面使用统一的低饱和主题色、纸张与留白；生成的书籍封面不重复标题，空白和有正文的笔记保持同一结构。
- 笔记列表支持标题／摘要搜索、重命名、移动和回收；笔记顶部引用默认折叠，仍可展开并回到原文。
- 笔记预览与 AI 回答支持代码块、复制代码、基础表格、有序／嵌套列表及斜体；原始 HTML 按文本显示。任务框仍是只读预览。
- 保存 AI 回答后继续保留原阅读位置和对话窗口；Esc 可收起对话，草稿仍保存。AI 入口统一使用星光图标。
- 修复窄屏 TXT／EPUB 的批注入口隐藏问题，独立表单保留键盘焦点提示；PDF 学习工具并入顶栏，窄屏时换行而不覆盖正文。
- EPUB 阅读外观支持跟随系统、浅色、暖纸和深色；PDF 显示实际缩放比例，支持适应页宽、已索引页面搜索和结果跳转。

## 验收范围

使用隔离书库中的原创 TXT、EPUB、PDF 和笔记，覆盖搜索范围、回收与恢复、部分失败、拖拽整理、引用回跳、Markdown、窄屏阅读、主题切换、笔记目录、截图协作和对话草稿。截图与原始测试结果保留在本地 `artifacts/`，不包含用户书库。

PDF 搜索使用已有文字索引；索引仍在生成或扫描页没有文字时，结果可能不完整。加密 PDF 不持久保存解密文字索引。复制接口不可用时会选中代码，供手动复制。

安装与实际宿主生效按 [本地更新方案](LOCAL_UPDATES.md) 分别核验；最终版本、来源提交和真实宿主截图以对应交付收据为准。
