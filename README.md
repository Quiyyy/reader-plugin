# Reader 0.1.5 原创书源示例（纯 JSON 数据）

这两个 JSON 可直接导入 Reader 的“在线书源”：`reader-demo-cdn.json` 是单对象，`reader-demo-cdn-array.json` 是数组。书源文本为 Reader 项目原创《河岸的两封信》，无账号、脚本、付费内容或第三方书库。

1. 打开书架的“在线书源”，展开“导入书源 JSON”。
2. 选择一个 JSON 文件，核对预览后确认导入。
3. 启用“Reader 原创公开示例 JSON”，选择这个源，输入“河岸”搜索。
4. 打开《河岸的两封信》详情，加入书架并阅读。
5. 目录有两章，第一章自动合并两页正文。保存书签后重开 Reader，可继续阅读。

也可将这些文件的公开 HTTPS URL 粘贴到 URL 导入框。源定义、搜索结果、详情、目录和正文均为 jsDelivr 提供的本项目公开 JSON 数据；正文固定在提交 `a5bddf2ece1d911b2ee899b3f2b340874190fafa`，不依赖可变的第三方书源集合。规则使用 Reader 支持的受限 JSONPath，仅提取纯文本字段，不含表达式或脚本。

这是固定目录演示，任何关键词都返回同一本原创样例，搜索第二页为空。首次读取需要公网，已读章节有缓存；停用书源仍可读缓存。在线正文搜索只检索当前章节。

原始 GitHub 域名在部分网络会连接失败，某些 CDN 节点还会将 HTML 文件重定向回该域名。本版提供独立的纯 JSON 数据，所有书籍链接均指向同源 JSON 文件，不需要跨域重定向或浏览器 HTML 资源。Reader 不继承代理或凭据，不绕过 TLS、SSRF、登录或访问控制。不支持 JS、Rhino、WebView 和复杂未知规则；这不是完整 Legado 兼容声明。

该目录只提供示例数据与说明，不含安装器或运行时代码，不改变正式插件及市场发布状态。
