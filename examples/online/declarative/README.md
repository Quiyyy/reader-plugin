# 0.1.7 原创声明式样例

这些短文和页面由 Reader 项目为验证与试读原创，没有第三方小说、登录、用户信息、远程图片或脚本。示例故意同时使用有限 XPath、负/排除索引、直接子节点、文本定位、HTML 转纯文本、正则清理和目录/正文分页。

需要 Reader **0.1.7 候选或更新版本**；正式 0.1.6 不支持这份新语法样例。它不会替你升级插件。

1. 在候选 Reader 的“找书”中打开“管理书源 → 导入书源”。
2. 选择此目录的 `reader-declarative.json`，或导入下方公开 JSON 链接。
3. 确认后启用“Reader 原创声明式验证样例”。输入“纸桥”并搜索，打开“原创纸桥”，点“开始阅读”。
4. 第一章应显示“折好的纸桥横跨浅浅的水洼。”和第二页的“纸桥的另一端留着一片叶子。”；不应显示清理标记“本章完”。目录应有两章。
5. 切到第二章“灯笼”，保存书签后返回书架。已读章节可从缓存恢复。正式网站的兼容性不能由这个样例推断。

[导入 JSON](https://raw.githubusercontent.com/Quiyyy/reader-plugin/refs/heads/feature/legado-reader-0.1.7-validation/examples/online/declarative/reader-declarative.json)

此公开演示是静态 GET 页面；关键词只用于演示编码，任意词都返回同一本原创短文。POST 的字面量表单与重定向边界另由本机原创测试服务覆盖，静态文件托管不接受搜索 POST。联网失败时查看具体错误；不要关闭 SSRF、证书或其他安全检查，也不要填入用户 Cookie/身份请求头。
